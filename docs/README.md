# OctoAcme Project Management Documentation

Welcome to the OctoAcme project management framework. This documentation provides comprehensive guidance for running projects from initiation through retrospective and continuous improvement.

## About OctoAcme Project Management

OctoAcme uses a structured, iterative approach to project management that balances planning with flexibility. Our methodology emphasizes customer value, clear ownership, data-driven decisions, and psychological safety. Whether you're launching a new product feature, managing a service integration, or delivering cross-functional initiatives, these guides will help you navigate each phase of the project lifecycle.

## Quick Start

New to OctoAcme? Start with the [Project Management Overview](octoacme-project-management-overview.md) to understand our approach, core roles, and key principles.

### 2. **Planning** — Build Your Roadmap

**Key deliverables**: Prioritized backlog, acceptance criteria, release plan, Definition of Done

📄 [Risk Management & Communication](octoacme-risks-and-communication.md) — Maintain the risk register, communicate status, and escalate issues.

**Key deliverables**: Risk register, status updates, stakeholder communications, escalation logs

### 5. **Release & Deployment** — Ship Safely
📄 [Release & Deployment Guide](octoacme-release-and-deployment.md) — Pre-release checklist, deployment process, rollback playbook.

**Key deliverables**: Release notes, deployment checklist, smoke test results, rollback plan

### 6. **Retrospective & Improvement** — Learn & Iterate
📄 [Retrospective & Continuous Improvement](octoacme-retrospective-and-continuous-improvement.md) — Capture learnings, track improvements, celebrate wins.

**Key deliverables**: Retrospective notes, action items, learnings document, improvement tracking

## Core Principles

- **Customer-first**: Prioritize customer value and usability
- **Iterative delivery**: Ship small, testable increments
- **Clear ownership**: Named PM and Product Lead per project
- **Data-informed**: Measure impact and iterate based on evidence
- **Psychological safety**: Encourage feedback and learning

## Communication Cadence

OctoAcme projects follow a regular communication rhythm:

- **Daily**: Team standups (15 min) — progress, blockers, dependencies
- **Weekly**: PM + PdM sync and delivery team sync — status updates and risk review
- **At milestone**: Demo/Review and retrospectives
- **As needed**: Stakeholder updates and escalations
